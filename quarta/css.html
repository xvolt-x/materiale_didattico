Selettore, proprietà e valore

  
Un foglio di stile è un elenco di regole. Ogni regola dice a quali elementi si applica e quali caratteristiche modificare.


  

    h1 { color: blue; /* Colore del testo blu */ }
  

  
Regola CSS

Integrazione HTML: i tag div e span

  
Due contenitori generici, uno a blocchi e uno in linea

  
p. 179

  
<div> è un contenitore a blocco: occupa tutta la larghezza e va a capo. <span> è un contenitore in linea: sta dentro al testo, senza spezzarlo. Da soli non fanno nulla: servono per applicare stili.

Il box model

  
Ogni elemento è composto da quattro strati: il contenuto, il padding (lo spazio dentro il bordo), il border (il bordo) e il margin (lo spazio fuori dal bordo).

Il concetto di cascata

  
Quando più regole colpiscono lo stesso elemento

  
Se più regole si applicano allo stesso elemento, vince la più specifica; a parità di specificità vince l'ultima scritta. Semplificando: tipo < classe < id < inline.
