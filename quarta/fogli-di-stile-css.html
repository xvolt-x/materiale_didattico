  01 · a cosa servono
  
HTML dice cosa, CSS dice come

  
p. 177

  
I CSS (Cascading Style Sheets, fogli di stile) definiscono l'aspetto delle pagine web. Qui sotto l'HTML resta sempre lo stesso: cambia solo il foglio di stile.

  

    
    
    
  

  

    

      
index.html invariato


<h4>Il mio sito</h4>
<nav>
  <a href="#">Home</a>
  <a href="#">Galleria</a>
  <a href="#">Contatti</a>
</nav>
<p>Benvenuti! Qui racconto i miei
progetti di programmazione.</p>

      
CSS nessuno

    

    

      
anteprima nel browser

      
Il mio sito
HomeGalleriaContatti
Benvenuti! Qui racconto i miei progetti di programmazione.

    

  

  
Ricorda → è il principio già visto nell'unità B1, la separation of concerns: contenuto e struttura da una parte (HTML), presentazione dall'altra (CSS). Si può cambiare uno senza toccare l'altro.

  03 · sintassi
  
Anatomia di una regola CSS

  
p. 178

  
Ogni regola ha sempre la stessa forma. Tocca le parti qui sotto per scoprirne il nome.

  

    
h1 {

    
color: blue; /* Colore del testo blu */

    
text-align: right; /* Testo allineato a destra */

    
}

  

  
Tocca una parte qui sopra
Selettore, blocco, dichiarazione, proprietà, valore, commento.

  
Ricorda → proprietà e valore sono separati da :; ogni dichiarazione finisce con ;; il blocco sta tra { }. Dimenticare un ; è l'errore più frequente.

  06 · div e span
  
Integrazione HTML: i tag div e span

  
p. 179-180

  
<div> è un elemento di blocco: occupa tutta la larghezza e va a capo. <span> è in linea: resta dentro il testo. Da soli non fanno nulla: servono per applicare stili.

  

    
    
    
  

  

    

      

        

          
divMenu

          
divContenuto principale

          
divInfo

        

        
Questo testo contiene uno span e un altro span: restano nella stessa riga del paragrafo.

      

      
div (blocco)span (in linea)

    

    
CSS applicato

  

  
Layout moderno → i div si usano al posto delle tabelle per disporre la pagina: con display: flex (o grid) le colonne si adattano alla larghezza. Le tabelle restano per i dati tabellari.

  10 · proprietà CSS
  
Le principali proprietà CSS

  
Queste proprietà permettono di modificare l'aspetto del testo, gli spazi, le dimensioni e i bordi degli elementi.


  
Proprietà per il testo

  

    
ProprietàValori ammessiSignificato

    
      
colorNome colori / rgb(n1,n2,n3) / esadecimaleColore del testo

      
background-colorNome colori / rgb(n1,n2,n3) / esadecimaleColore di sfondo

      
text-alignleft / right / centerAllineamento orizzontale del testo nel contenitore (solo per span e p)

      
text-transformuppercase / lowercase / capitalizeForza maiuscolo o minuscolo

      
font-sizeMisura in pixel (es. 18px), percentuale (es. 120%), rispetto al testo genitore (es. 1.5em) / small / largeDimensione del carattere

      
font-weightnormal / bold / numero da 100 a 900Spessore del carattere (grassetto)

      
font-stylenormal / italic / obliqueCorsivo

      
font-familyArial / Calibri / Garamond … (anche più di un valore, in caso non fosse disponibile)Tipo di carattere

    
  


  
Proprietà per spazi e bordi

  

    
ProprietàValori ammessiSignificato

    
      
paddingMisura in pixel (es. 10px) o rispetto al testo (es. 1.5em), da 1 a 4 valori (top/right/bottom/left)Distanza tra il contenuto e il bordo del contenitore (verso l'interno)

      
marginMisura in pixel, anche negativa, oppure auto, da 1 a 4 valoriDistanza del contenitore dagli altri elementi (verso l'esterno)

      
widthMisura in pixel / em / percentuale / rem (pagina) / vw (finestra browser) oppure autoLarghezza del contenitore

      
border (border-left)3 valori: spessore, stile, coloreFormattazione di tutto il bordo del contenitore

      
border-radiusMisura in pixel / in percentualeArrotondamento degli angoli

      
border-stylesolid / dashed / dotted / double / noneStile del bordo (solido, tratteggiato, ecc.)

      
displayblock / inline / inline-block / flex / noneCome l'elemento si comporta nella pagina (a capo, in linea, allineato agli altri, …)
