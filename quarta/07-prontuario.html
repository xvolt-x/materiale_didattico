01 · HTML

Pagina e contenuti

Struttura

<!DOCTYPE html>
<html lang="it">
<head>
  <meta charset="UTF-8">
  <title>...</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  ...
</body>
</html>

Testo

<h1>...</h1>  <h2>...</h2>  <h3>...</h3>
<h4>...</h4>  <h5>...</h5>  <h6>...</h6>
<p>...</p>
<br>
<strong>...</strong>
<em>...</em>
<!-- commento -->

Link e immagini

<a href="pagina.html">...</a>
<a href="https://www.sito.it" target="_blank">...</a>
<a href="#id-elemento">...</a>
<img src="img/foto.jpg" alt="..." width="300">

Elenchi

<ul>
  <li>...</li>
</ul>

<ol>
  <li>...</li>
</ol>

Tabelle

  <tr>
    <th>...</th>

  </tr>

    <td>...</td>
    <td>...</td>

02 · Form

Tag, tipi di campo e attributi

Tag

<form action="/..." method="post">  </form>
<form action="/..." method="get">  </form>

<label for="x">...</label>
<input type="..." id="x" name="x">

<textarea id="..." name="..." rows="4"></textarea>

<select id="..." name="...">
  <option value="...">...</option>
  <option value="..." selected>...</option>
</select>

<input type="radio" id="..." name="..." value="...">
<input type="radio" id="..." name="..." value="..." checked>
<input type="checkbox" id="..." name="..." value="...">

<fieldset>
  <legend>...</legend>
</fieldset>

<button type="submit">...</button>
<button type="reset">...</button>

Valori di type

text · email · password · tel · url
number · date · time · color · range
file · radio · checkbox · submit · reset

Attributi dei campi

placeholder="..."
value="..."
required
minlength="3"     maxlength="200"
min="1"           max="10"
min="2026-01-01"  max="2026-12-31"
step="0.5"
pattern="[0-9]{5}"
pattern="[A-Z]{2}[0-9]{3}"
checked
selected
03 · CSS: sintassi

Dove si scrive, regole e selettori

Dove si scrive

<link rel="stylesheet" href="css/style.css">

<style>
  ...
</style>

<p style="color: red;">...</p>

Regola

selettore {
  proprietà: valore;
  proprietà: valore;
}

/* commento */

Selettori

p { }
.nome-classe { }
#nome-id { }
h1, h2, p { }
.scheda p { }

Pseudo-classi

a:hover { }
button:hover { }
input:focus { }
input:user-invalid { }
input:invalid { }
